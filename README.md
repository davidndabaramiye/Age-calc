# AI Age Calculator

A simple static website that calculates a user's age from their date of birth. Enter a birth date, click the button, and the page generates the age in years, months, and days.

## Files

- `index.html` — page structure and content
- `styles.css` — layout and styling
- `script.js` — age calculation logic

## Usage

Open `index.html` in a browser to use the calculator.
